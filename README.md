# Mahanyu Nature Guide

Static GitHub Pages website for **Mahanyu Nature Guide**.

## Publish on GitHub Pages

1. Push this folder to a GitHub repository.
2. Open the repository settings.
3. Go to **Pages**.
4. Set the source to the `main` branch and root folder.
5. Save.

No build step is needed. GitHub Pages can serve `index.html` directly.

## Replace images

All replaceable photos live in `assets/images/`. To change a photo, keep the same filename and replace the file.

| Filename | Used for |
| --- | --- |
| `image-header.jpg` | Main hero image and one gallery image |
| `image-section-about.jpg` | About section and one gallery image |
| `image-section-lodge.jpg` | Lodge/gallery image |
| `image-trek-1.jpg` | First trek card |
| `image-trek-2.jpg` | Second trek card |
| `image-trek-3.jpg` | Third trek card |
| `image-section-cta.jpg` | Custom trip call-to-action background |

Use `.jpg` files with the same names for the quickest swap. Landscape images work best for the header, trek cards, gallery, and CTA. A portrait or square image also works well for the about section.
